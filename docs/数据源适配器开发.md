# Vuln KB 数据源适配器开发说明

新增来源必须复用公共导入与审核流水线。适配器只负责发现和读取公开来源，不创建正式漏洞、不设置审核通过，也不执行下载内容。

## 优先用声明式 Feed 映射

1. 将配置加入 `configs/sources.yml`（可以从 `configs/sources.example.yml` 复制）。
2. 为来源分配唯一 `key`，声明 `rss` 或 `json_feed`、HTTPS `feed_url`、精确 `allow_hosts` 主机列表和字段映射。
3. `material_url` 应指向 PoC/EXP/完整复现文档；公告/漏洞编号页可以作为原始链接，但单靠公告不能通过材料门槛。
4. 重启 Worker，然后在管理员页面按配置中的来源 key 创建采集任务。
5. 观察分区游标、发现/已处理计数、候选审核原因和来源修订。

映射路径使用点号访问嵌套 JSON，如 `license.spdx_id`。RSS 映射读取 `<item>` / `<entry>` 的直接子元素；`link href` 会作为链接值。Feed 响应和单份材料上限均为 10 MiB。适配器禁用 HTTP 重定向，只允许配置中精确列出的 HTTPS 主机。

示例：

```yaml
sources:
  - key: example_poc_feed
    type: json_feed
    feed_url: https://security.example.org/poc-feed.json
    allow_hosts: [security.example.org, files.security.example.org]
    items_path: items
    fields:
      id: id
      title: title
      url: html_url
      material_url: download_url
      revision: commit
      license: license.spdx_id
```

## 实现代码插件

字段映射不能表达来源分页、认证或版本语义时，实现 `SourceAdapter` Protocol，并通过 Python entry point `vuln_kb.adapters` 注册。插件导出的 `key` 必须与 entry point 名称相同。

```python
class ExampleAdapter:
    key = "example_source"

    async def probe(self) -> dict: ...
    async def discover(self, partition: str, cursor: str | None = None, budget: int = 100) -> DiscoveryPage: ...
    async def fetch(self, ref: SourceRef) -> RawSnapshot: ...
```

返回对象定义在 `vuln_kb.adapters.contracts`。发现页必须提供稳定可恢复的游标；`SourceRef` 至少提供 source key、稳定 external ID、标题和原始来源 URL。材料下载 URL 可以放在 `metadata.download_url`，但必须执行 HTTPS、主机白名单和大小校验。`RawSnapshot.content` 可返回 `bytes`，也可返回异步字节流；较大材料优先返回流，公共导入层会边下载边写入限额暂存对象并计算 SHA-256。保存内容前应能确定来源修订；拿不到固定修订时明确返回 `None`，不要伪造 commit/hash。

插件应由部署方审阅后安装：Python entry point 会在 Worker 进程中运行。来源代码只返回快照，写入对象仓库、存储 provenance、去重、AI 评估和发布均由 Vuln KB 公共流程处理。禁止插件运行 PoC/EXP、跳过预算、读取不相关密钥或自行标记材料/漏洞已验证。

## 接入验收清单

- 对 fixture 验证正常页、空页、重复 ID、坏字段、限额、断点续采、超时和限流错误。
- 固定来源 URL、commit/revision、文件路径、许可证提示和 SHA-256。
- 用一个真实只读样本观察：发现 → 快照 → 材料 → AI 审核 → 搜索/候选，未合格内容不得发布。
- 429、权限错误、来源结构变化要显示在任务/覆盖状态，不能被当成“已完整同步”。
- 确认采集请求不接受用户任意 URL、不跟随到未允许主机、不连接私有或 loopback 地址。
- 确认新来源只需添加映射/独立插件，不修改搜索接口和通用发布门槛。

当前配置式实现适用于简单 RSS/JSON Feed；认证、分页、API 专用配额或多段附件需要独立插件。Sploitus/HackerOne 等站点必须先探测公开可访问能力，不假设有 API 或可读取非公开报告正文。
